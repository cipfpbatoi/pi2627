# Iteració 5.1. Prova tècnica inicial

**Sessions 1–2 · 6 hores**

## Propòsit

Comprovar que el pla rebut es pot començar i reduir la incertesa tècnica que podria impedir el recorregut principal.

1. Llegiu `pla-v1.0` sense explicació inicial i completeu `traspassos/02-pla-a-prototip.md`. Registreu accessos, dependències, permisos, reserves i resultat de l'acceptació.
2. Seleccioneu un risc tècnic concret i definiu abans de provar-lo què demostrarà l'èxit o el fracàs. Pot ser una integració, persistència, autenticació, accessibilitat o desplegament, segons el projecte.
3. Prepareu l'entorn, una prova executable i les instruccions perquè una altra persona la repetisca. Useu dades de prova i no publiqueu secrets.
4. Compareu el resultat amb el pla. Obriu incidència o proposta de canvi si afecta abast, temps, costos, riscos o proves.

**Evidència:** acta T05, commit o release T06, prova i resultat, instruccions d'entorn i [informe d'iteració](bloc5-informe-iteracio.md). Cada membre enllaça una aportació i una revisió.

**Comprovació:** què s'ha confirmat, què continua incert i quin és el primer flux que es pot implementar?

**RA/CA:** RA4.a–e, evidència parcial de l'aplicació del control; RA3.a–h, parcial només si hi ha revisió justificada del pla.
